📋 One-time Google Sheet setup required

To enable profile approvals and password management from this panel, add an Approved column and a Settings tab to your Google Sheet.

1

Open your TAS Connect Members Google Sheet. In the first row of the responses tab, add a new column header: Approved — type it exactly like that.

2

For each existing member row, type yes in the Approved column to make them live, or leave blank to keep them hidden.

3

Add a second sheet tab — click the + at the bottom of the sheet and name it exactly Settings.

4

In the Settings tab, put Key in cell A1 and Value in cell B1. Then in A2 put member_password and in B2 put your chosen member password.

5

Update config.js — add your Settings tab Sheet URL as SETTINGS_URL. The format is the same as your main sheet URL but with &sheet=Settings added to the end.

🛡️ Admin Password

Your admin panel password is set in config.js in GitHub as ADMIN_PASSWORD. To change it, edit that file and push to GitHub — Netlify will redeploy automatically.

Current admin password is stored in config.js only — it cannot be changed from here for security reasons.

✅ Approval Tips

Profile approvals work by updating the Approved column in your Google Sheet. You can approve/reject from this panel, and it will show you the instructions to update the sheet.

Since this is a no-backend setup, approvals work by giving you the row number to update in the sheet directly. A future upgrade to Supabase would make this fully automatic.
